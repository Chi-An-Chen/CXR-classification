# Inputs and outputs of the chest X-ray classifier

Use the repository root as the working directory. [main.py](main.py) controls training, model selection, and prediction. [dataloader.py](dataloader.py) reads the image filename and labels from the CSV for each split.

| Use | Supply | Output |
|---|---|---|
| Train and validate | `datasets/train_data.csv`, `datasets/val_data.csv`, and corresponding images in `datasets/train_images/` and `datasets/val_images/` by default. The CSVs are tracked; supply the image folders. | A validation-selected checkpoint under `results/<run>/best_<backbone>.pt` and training/validation statistics. |
| Predict | A matching backbone and checkpoint for `--test-only`, plus test images in `datasets/test_images/` or the directory passed to `--test-dir`. | Predicted labels in `--out-csv` (default `Submission.csv`); the TTA path supports `--save-probs` for per-class probabilities. |

The [saved EfficientNet V2 M report](results/2025-11-02/report_efficientnet_v2_m.txt) labels its tables **Train** and **Val**. A submission CSV contains predictions; it does not establish held-out test performance. The weights required by the README's test-only example must be supplied or generated by training.
